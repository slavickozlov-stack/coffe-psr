# ГОСТ-Документ (GOST DocFlow)

> **Автоматизированное рабочее место (АРМ) подготовки, оформления и нормоконтроля технической и отчетной документации по стандартам ГОСТ.**  
> Разработано с ориентацией на профильные инженерные и отраслевые направления (работники АЭС, электромонтеры, сварщики, бухгалтеры) и учебные заведения (ВИТИ НИЯУ МИФИ).

## ✨ Основные возможности

1. **Отраслевая специализация**:
   - **Работники АЭС**: отчеты по регламентам энергоблоков ВВЭР-1200, барьеры глубокоэшелонированной защиты, нормы НП-001-15.
   - **Электрик**: протоколы испытаний электрооборудования, сопротивление изоляции, контуры заземления, нормы ПУЭ-7.
   - **Сварщик**: технологические карты сварки, контроль сварных соединений по ГОСТ 5264-80.
   - **Бухгалтер**: акты инвентаризации, учет основных средств, оформление первички по 402-ФЗ.

2. **Строгое соблюдение ГОСТ 7.32-2017 и ГОСТ 2.105-2019 при экспорте в `.docx` и `.txt`**:
   - Поля страницы: левое — 30 мм, правое — 15 мм, верхнее — 20 мм, нижнее — 20 мм.
   - Шрифт: **Times New Roman, 14 pt**.
   - Межстрочный интервал: **1.5 (полуторный)**.
   - Абзацный отступ (красная строка): **1.25 см**.
   - Выравнивание основного текста по ширине.
   - Титульный лист с реквизитами организации, исполнителя и проверяющего.

3. **Автоматическая библиография**:
   - При изучении документа в правой панели можно нажать кнопку **«Цитировать в отчет»** (или выделить любой фрагмент).
   - Выбранная цитата сразу вставляется в текст отчета, а данный нормативный документ **автоматически заносится в список использованных источников** по ГОСТ Р 7.0.5.

4. **Интегрированная нейросеть-аналитик (ИИ)**:
   - **«Выжимка нейросетью»**: мгновенный анализ нормативного акта и генерация структурированного конспекта с ключевыми требованиями.
   - **Интерактивный чат**: ответы на вопросы по тексту любого регламента.
   - **Авто-нормоконтроль**: проверка отчета на незаполненные поля (`[ВВЕДИТЕ ...]`), наличие реквизитов и библиографии с выставлением баллов (Score 0-100).

5. **Полный цикл взаимодействия «Сдающий ↔ Проверяющий»**:
   - Автор заполняет работу и нажимает **«Отправить на проверку»**.
   - Проверяющий в **Личном кабинете нормоконтролера** открывает документ, скачивает его или читает прямо в интерфейсе, выделяет спорные моменты и оставляет замечания.
   - Проверяющий может **«Утвердить»** документ или **«Отправить обратно на доработку»**.
   - Сдающий мгновенно видит статус «На доработке», видит все замечания проверяющего в верхнем баннере и может прямо в центральном окне внести правки и отправить повторно.

## 🛠 Установка и запуск

### 1. Клонирование и переход в каталог
```bash
git clone https://github.com/slavickozlov-stack/gost-doc-platform.git
cd gost-doc-platform
```

### 2. Активация виртуального окружения и установка зависимостей
```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 3. Запуск сервера
```bash
python3 app.py
```
После запуска откройте в браузере: **http://127.0.0.1:8000**
